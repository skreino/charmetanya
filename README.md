# Charme Tanya

Landing page premium per Charme Tanya, salone di acconciature, estetica e benessere a Busnago.

## Avvio locale

```bash
npm install
npm run dev
```

## Verifica

```bash
npm run build
npm run start -- -H 127.0.0.1 -p 3001
npm run test:responsive
```

Il test controlla i breakpoint 375, 768, 1440 e 1920 px, l'assenza di overflow e la presenza delle CTA principali.
